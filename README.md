# LoK: Defiance Remastered PL
## Status tłumaczenia: **Częściowo wstrzymane**
Z przykrością musimy was zawiadomić, że spolszczona wersja gry Defiance Remastered nie pojawi się tak szybko,
jak tego oczekiwaliśmy.

Studio odpowiedzialne za Remaster wykonało go w taki sposób, że nie da się łatwo edytować plików gry,
tak jak było to możliwe w przypadku Remasteru Soul Reaver 1&2.

Obecnie pracujemy nad narzędziami, które umożliwią:
- wyciągnięcie danych z pliku `bigfile.x64.dat` do ich edycji (część trywialna)
- spatchowanie pliku `bigfile.x64.dat` danymi polonizacyjnymi już po stronie użytkownika (część znacznie bardziej skomplikowana z różnych względów technicznych)

Na tę chwilę nie deklarujemy się na żadne terminy ukończenia prac nad tłumaczeniem, gdyż nie mamy gwarancji,
czy faktycznie nasza praca poskutkuje działającą, spolszczoną grą.

Jeśli chcesz wesprzeć nasze zmagania z nieprzychylnymi warunkami przy tworzeniu tego spolszczenia,
rozważ postawienie nam wirtualnej kawy:

## Translation status: **Partially suspended**
We regret to inform you that the Polish translation of *Defiance Remastered* will not be released as soon as we anticipated.

The studio responsible for the remaster prepared the game in such a way that the game files cannot be easily modified,
unlike in the case of the *Soul Reaver 1 & 2 Remastered* release.

We are currently working on tools that will allow us to:
- extract data from the `bigfile.x64.dat` archive for editing (the relatively easy part)
- patch the `bigfile.x64.dat` archive with the Polish translation on the user's side (a significantly more complicated task due to various technical constraints)

At this point we are unable to provide any estimated release date for the translation,
as we cannot guarantee that our work will ultimately result in a fully working Polish version of the game.
